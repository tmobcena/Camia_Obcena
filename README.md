# Program Title: Hypotenuse Calculator

## Discription
This program calculates the hypotenuse of a right-angled triangle.

## How to Run
In order to run the program, you must download the file, press the play button, and enter your side values.

## Input Needed
We need to input the lengths of side a and b.

## Sample Output
Enter the length of side a: 4

Enter the length of side b: 8

The hypotenuse is: 8.94
